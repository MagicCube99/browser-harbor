# Browser Harbor v0.2.1

Bug-fix release for safe browser relocation and reliable window restoration.
浏览器重新定位安全性与窗口恢复可靠性修复版。

## 下载 · Download

Download **BrowserHarbor-0.2.1-x64.exe**. This EXE is sufficient for normal use.

普通使用只需下载 **BrowserHarbor-0.2.1-x64.exe**。

The separately attached manifest, signature, and public key are optional for independent verification.

另附的清单、签名和公钥仅用于独立验证，可选下载。

## 修复 · Fixes

- Relocation rejects a known different browser even when the candidate executable has the same filename. Unknown custom programs show an identity warning before confirmation.
- Saved window positions are clamped to the current virtual desktop after display changes.

## 其他 · Other

- The Chrome++ page now links to the upstream source and GPL-3.0 license.
- Public documentation is focused on installation, use, verification, and troubleshooting.

## 当前限制 · Current limitations

- Brave, Helium, and Ungoogled Chromium retain an experimental Chrome++ compatibility label.
- The EXE is not Authenticode-signed, so SmartScreen may show a warning.
- Existing arbitrary browser directories are not imported automatically.
