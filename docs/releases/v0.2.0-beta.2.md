# Browser Harbor v0.2.0-beta.2 — Verified Edition Beta

Removes operational expiry from signed metadata and enables daily manifest refresh without publishing another EXE.
取消签名元数据的实际操作有效期，并启用无需再次发布 EXE 的每日清单刷新。

## 下载 · Download

Download only **BrowserHarbor-0.2.0-beta.2-x64.exe**.

只需下载 **BrowserHarbor-0.2.0-beta.2-x64.exe**。

## 可选验证资产 · Optional verification assets

These files are embedded in the EXE and are not required for normal use:

- **trusted-metadata.json**
- **trusted-metadata.sig**
- **metadata-public-key.hex**

## 主要变化 · Changes

- Ed25519 signatures remain valid until the project key is rotated or revoked; there is no date-based signature expiry.
- The client refreshes a verified signed manifest at most once per day.
- A scheduled GitHub workflow checks upstream versions and signs a replacement manifest only when content changes.
- Routine metadata updates do not create a new EXE, tag, or Release.

## 兼容性 · Compatibility

`v0.1.0` remains the frozen compatibility release. `v0.2.0-beta.1` remains available for comparison but may reuse a signed manifest cache for too long.
