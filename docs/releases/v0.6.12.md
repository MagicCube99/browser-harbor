## 本次更新 · Changes since v0.6.8

- 新增 Vivaldi 下载与便携安装，并明确提示其官方密码跨机迁移限制；建议提前使用 Vivaldi Sync。
- 修复 Edge 安装失败，以及上游信息过旧、首次安装误报 Chrome++ 升级等提示问题。
- 加快版本检查，减少网络不佳时的等待；下载校验规则不变。
- Brave 新版本尚未提供 Windows 安装包时，使用同渠道已可下载的版本。

- Added Vivaldi downloads and portable setup, with a notice explaining its official password-migration limitation and recommending Vivaldi Sync.
- Fixed Edge installation failures, stale upstream information, and misleading Chrome++ upgrade notices on fresh installs.
- Made version checks faster and reduced waits on poor connections, while keeping download verification intact.
- Brave now selects the latest available Windows package in the chosen channel when a new release is still being uploaded.

## 使用提醒 · Note

部分远程桌面环境可能出现启动失败，请尝试在本地桌面运行。本版未改动图形兼容性。

The app may fail to open in some Remote Desktop environments. Try running it on the local desktop. Graphics compatibility is unchanged in this release.
