# Browser Harbor v0.1.0

First stable release: one portable EXE for verified downloads, portable installation, updates, configuration, and health repair across 14 Windows browser targets.  
Browser Harbor v0.1.0 首个稳定版本：用一个便携 EXE 完成 14 个 Windows 浏览器目标的下载校验、便携安装、更新、配置和健康修复。

Status: frozen Compatibility Edition. Its release metadata is not project-signed.
状态：已冻结的兼容版；其发布元数据没有经过本项目签名。

## 下载 · Download

Download **BrowserHarbor-0.1.0-x64.exe** from the GitHub Release and run it directly. No installer, administrator rights, service, or WebView2 runtime is required.  
从 GitHub Release 下载 **BrowserHarbor-0.1.0-x64.exe** 并直接运行。无需安装、管理员权限、后台服务或 WebView2。

Requires Windows 10 22H2 or Windows 11, x64.  
需要 Windows 10 22H2 或 Windows 11 x64。

## 主要功能 · Highlights

- 14 Chromium/Firefox-family targets with independent Browser Root, program, data, profile, and cache paths.  
  支持 14 个 Chromium/Firefox 系目标，每个目标独立保存 Browser Root、程序、数据、Profile 和缓存路径。
- Verified downloads, controlled extraction, staged installation, atomic replacement, rollback, and browser-running protection.  
  下载校验、受控解压、暂存安装、原子替换、失败回滚和浏览器运行中保护。
- Full Chrome++ configuration and required Libportable integration where applicable.  
  支持目标使用完整 Chrome++；官方 Firefox 与 Zen 强制 Libportable。
- Read-only health checks, Chrome++/portable INI repair, relocation preview, browser identity validation, and stable Edge version resolution.  
  只读配置检查、Chrome++/便携 INI 修复、重新定位预览、浏览器身份校验和稳定的 Edge 版本目录解析。
- Immediate autosave, system/light/dark appearance, fixed compact UI, saved window position, and single-instance protection.  
  立即自动保存、跟随系统/浅色/深色外观、固定紧凑界面、窗口位置恢复和单实例保护。
- Chinese and English interface switching with a persisted preference.  
  中英文界面切换，并持久保存语言偏好。

## 支持目标 · Supported targets

- Chromium: Brave, Catsxp, Chrome, Edge, Helium, Thorium, Turbo, Ungoogled Chromium.
- Firefox: Firefox, Floorp, Iceweasel, LibreWolf, SkyKakapo, Zen.

Brave, Helium, and Ungoogled Chromium retain experimental Chrome++ compatibility labels.  
Brave、Helium、Ungoogled Chromium 仍保留实验性 Chrome++ 兼容标记。

## 第一次打开 · First launch

Windows may show “Windows protected your PC” because the executable is not Authenticode-signed. Choose **More info → Run anyway**.  
由于 EXE 尚未做 Authenticode 签名，Windows 可能提示“Windows 已保护你的电脑”。请选择 **更多信息 → 仍要运行**。

The manager configuration is stored at `%LOCALAPPDATA%\browser-harbor\manager.json`.  
管理器配置保存在 `%LOCALAPPDATA%\browser-harbor\manager.json`。
