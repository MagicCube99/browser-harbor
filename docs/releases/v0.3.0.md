# Browser Harbor v0.3.0

Firefox-family browsers are now portable when their browser executable is launched directly.
所有 Firefox 系浏览器现在直接启动浏览器 EXE 即可保持便携，不再依赖发行包内的启动器。

## 下载 · Download

Download **BrowserHarbor-0.3.0-x64.exe**. This EXE is sufficient for normal use.

普通使用只需下载 **BrowserHarbor-0.3.0-x64.exe**。

GitHub unavailable? Use the [Gitee mirror](https://gitee.com/MagicCube99/browser-harbor/releases).

无法访问 GitHub 时，可从 [Gitee 镜像](https://gitee.com/MagicCube99/browser-harbor/releases)下载。

The separately attached manifest, signature, and public key are optional for independent verification.

另附的清单、签名和公钥仅用于独立验证，可选下载。

## 主要变化 · Highlights

- Floorp and LibreWolf now use mandatory Libportable injection instead of package launchers.
- Firefox, Floorp, LibreWolf and Zen are redirected at `mozglue.dll`; Iceweasel and SkyKakapo keep their native direct runtimes.
- Floorp preserves `data/profile/default`; LibreWolf preserves `Profiles/Default`.
- Bundled Floorp/LibreWolf launchers and LibreWolf updater/task scripts are removed to prevent launch and update conflicts.
- Configuration schema v11 migrates only known old default profile paths and preserves custom paths.
- Libportable installation fails unless `mozglue.dll` actually imports `portable64.dll`.

## 当前限制 · Current limitations

- Brave, Helium, and Ungoogled Chromium retain an experimental Chrome++ compatibility label.
- The EXE is not Authenticode-signed, so SmartScreen may show a warning.
- Existing arbitrary browser directories are not imported automatically.
