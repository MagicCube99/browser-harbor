## 本次更新 · What's new

- 安装或升级被“浏览器仍在运行”挡住时，提示会列出检测到的进程名称与 PID（最多 3 个），可以直接在任务管理器中定位并关闭对应进程。
- 检测不再把 Browser Harbor 自身进程计入“浏览器仍在运行”，工具与浏览器放在同一目录时不会误拦自己。

- When an installation or upgrade is blocked because the browser is still running, the message now lists the detected process names and PIDs (up to three), so you can find and close the exact process in Task Manager.
- Browser Harbor no longer counts its own process as a running browser, so the tool cannot block itself when it sits inside the browser directory.

## 升级 · Upgrade

直接替换旧 EXE 即可。`BrowserHarbor.json`、已安装浏览器、用户数据、Profile 和缓存不会被删除。

Replace the old EXE. `BrowserHarbor.json`, installed browsers, user data, profiles, and caches are not removed.
