# Browser Harbor v0.5.4

This patch renames the manager configuration to `BrowserHarbor.json` and adds a
safe one-time migration from the legacy `manager.json` name.

本次补丁把管理器配置统一命名为 `BrowserHarbor.json`，并为旧 `manager.json`
提供安全的一次性迁移。

## 下载 · Download

Download **BrowserHarbor-0.5.4-x64.exe**. This EXE is sufficient for normal use.

普通使用只需下载 **BrowserHarbor-0.5.4-x64.exe**。

GitHub unavailable? Use the [Gitee mirror](https://gitee.com/MagicCube99/browser-harbor/releases).

无法访问 GitHub 时，可从 [Gitee 镜像](https://gitee.com/MagicCube99/browser-harbor/releases)下载。

The separately attached manifest, signature, and public key are optional for independent verification.

另附的清单、签名和公钥仅用于独立验证，可选下载。

## 调整 · Changed

- User and portable configurations now use `BrowserHarbor.json`.
- A legacy `manager.json` is copied, verified, and then removed on the next launch.
- If old and new files contain different settings, the active new file is kept and the old one is saved under a numbered backup name.

- 用户目录和便携模式下的配置统一使用 `BrowserHarbor.json`。
- 下次启动会复制并校验旧 `manager.json`，成功后再删除旧文件。
- 新旧配置内容不同时保留当前新配置，并把旧文件保存为编号备份。

## 当前限制 · Current limitations

- Brave, Helium, and Ungoogled Chromium retain an experimental Chrome++ compatibility label.
- The EXE is not Authenticode-signed, so SmartScreen may show a warning.
