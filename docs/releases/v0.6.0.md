# Browser Harbor v0.6.0

Browser Harbor now offers useful release channels beyond Stable and checks the
existing executable's channel before replacing program files.

Browser Harbor 现在支持 Stable 之外的实用发布渠道，并会在替换程序文件前检查
现有 EXE 所属渠道。

## 下载 · Download

Download **BrowserHarbor-0.6.0-x64.exe**. This EXE is sufficient for normal use.

普通使用只需下载 **BrowserHarbor-0.6.0-x64.exe**。

GitHub unavailable? Use the [Gitee mirror](https://gitee.com/MagicCube99/browser-harbor/releases).

无法访问 GitHub 时，可从 [Gitee 镜像](https://gitee.com/MagicCube99/browser-harbor/releases)下载。

The separately attached manifest, signature, and public key are optional for independent verification.

另附的清单、签名和公钥仅用于独立验证，可选下载。

## 新增 · Added

- Chrome and Edge: Stable and Beta.
- Firefox: Stable, ESR, and Beta.
- Brave: Stable and Beta, selected by official release names.
- Installing a different channel into an existing Browser Root now requires confirmation.

- Chrome、Edge：Stable、Beta。
- Firefox：Stable、ESR、Beta。
- Brave：Stable、Beta，按官方 Release 名称选择。
- 在已有 Browser Root 中安装其他渠道时，需要先确认。

## 修复 · Fixed

- Brave Stable no longer resolves to the latest Nightly release.
- Libportable accepts tested Firefox 159 and 160 Beta while rejecting untested 161 Nightly.
- The cache-directory placeholder is now concise while its full explanation remains on hover.

- Brave Stable 不再被解析为最新 Nightly。
- Libportable 接受已实测的 Firefox 159 和 160 Beta，继续拒绝未验证的 161 Nightly。
- 缓存目录输入框使用精简占位文字，完整说明保留在悬停提示中。

## 当前限制 · Current limitations

- Edge Beta uses Microsoft's live CDP artifact URL, so it is resolved online but is not stored in the long-lived signed metadata manifest.
- Brave, Helium, and Ungoogled Chromium retain an experimental Chrome++ compatibility label.
- The EXE is not Authenticode-signed, so SmartScreen may show a warning.
