# Browser Harbor v0.5.3

This patch makes the cache-directory explanation easier to understand and
aligns the configuration dialog title with the button that opens it.

本次补丁简化了缓存目录说明，并让配置弹窗与入口按钮统一使用“检查配置”。

## 下载 · Download

Download **BrowserHarbor-0.5.3-x64.exe**. This EXE is sufficient for normal use.

普通使用只需下载 **BrowserHarbor-0.5.3-x64.exe**。

GitHub unavailable? Use the [Gitee mirror](https://gitee.com/MagicCube99/browser-harbor/releases).

无法访问 GitHub 时，可从 [Gitee 镜像](https://gitee.com/MagicCube99/browser-harbor/releases)下载。

The separately attached manifest, signature, and public key are optional for independent verification.

另附的清单、签名和公钥仅用于独立验证，可选下载。

## 调整 · Changed

- The cache hint now explains that browser cache is stored below the selected directory by Profile.
- “Check configuration” is used consistently for both the action and its dialog title.

- 缓存说明现在直接解释浏览器缓存会按 Profile 存放在所选目录下。
- 入口按钮和弹窗标题统一使用“检查配置”。

## 当前限制 · Current limitations

- Brave, Helium, and Ungoogled Chromium retain an experimental Chrome++ compatibility label.
- The EXE is not Authenticode-signed, so SmartScreen may show a warning.
