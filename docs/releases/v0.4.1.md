# Browser Harbor v0.4.1

This patch makes missing browser directories and incomplete installations explicit instead of presenting an old install receipt as the current version.

本次补丁明确区分目录缺失和安装不完整，不再把旧安装回执显示成当前版本。

## 下载 · Download

Download **BrowserHarbor-0.4.1-x64.exe**. This EXE is sufficient for normal use.

普通使用只需下载 **BrowserHarbor-0.4.1-x64.exe**。

GitHub unavailable? Use the [Gitee mirror](https://gitee.com/MagicCube99/browser-harbor/releases).

无法访问 GitHub 时，可从 [Gitee 镜像](https://gitee.com/MagicCube99/browser-harbor/releases)下载。

The separately attached manifest, signature, and public key are optional for independent verification.

另附的清单、签名和公钥仅用于独立验证，可选下载。

## 修复 · Fixed

- A deleted Browser Root or Program Directory now shows **Directory missing** and **Not installed**.
- A Program Directory without the expected browser executable now shows **Installation incomplete**.
- The install receipt is no longer treated as the current version; it remains available as last-install hover detail.
- Configured paths and install receipts are preserved for in-place reinstall or temporary external-drive disconnection.
- An uninstalled Chrome++ runtime no longer shows a stored old version.
- Truncated footer and Chrome++ version labels no longer show duplicate hover tooltips.
- The shortcut toggle aligns with the directory field right edge.

- Browser Root 或程序目录被删除时显示“目录不存在”和“未安装”。
- 程序目录缺少预期浏览器 EXE 时显示“安装不完整”。
- 安装回执不再冒充当前版本，只作为“上次安装记录”悬停信息保留。
- 保留已配置路径和安装回执，支持原地重装以及移动硬盘临时断开。
- Chrome++ 未安装时不再显示此前保存的旧版本。
- 截断的底栏状态和 Chrome++ 版本标签不再出现重复悬停提示。
- 快捷方式开关与目录输入框右边界对齐。

## 当前限制 · Current limitations

- Brave, Helium, and Ungoogled Chromium retain an experimental Chrome++ compatibility label.
- The EXE is not Authenticode-signed, so SmartScreen may show a warning.
- Existing arbitrary browser directories are not imported automatically.
