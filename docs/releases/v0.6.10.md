# Browser Harbor v0.6.10

Fixes Edge 156 installation failures.

修复 Edge 156 安装时的解压失败问题。

## 下载 · Download

Download **BrowserHarbor-0.6.10-x64.exe**. This EXE is sufficient for normal use.

普通使用只需下载 **BrowserHarbor-0.6.10-x64.exe**。

GitHub unavailable? Use the [Gitee mirror](https://gitee.com/MagicCube99/browser-harbor/releases).

无法访问 GitHub 时，可从 [Gitee 镜像](https://gitee.com/MagicCube99/browser-harbor/releases)下载。

## 调整与修复 · Changes & Fixes

- Edge Stable and Beta now resolve Microsoft's official CDP 7z payload instead of the Enterprise MSI bootstrapper.
- The payload is handled by the existing controlled self-extracting 7z path and exposes `MSEDGE.7Z` for the normal Edge layout builder.
- Long-lived signed metadata no longer keeps obsolete Edge MSI entries.

- Edge Stable 和 Beta 现在解析 Microsoft 官方 CDP 7z 制品，不再选择 Enterprise MSI 引导包。
- 该制品沿用现有受控自解压 7z 流程，并提供 `MSEDGE.7Z` 供 Edge 目录组装。
- 长期签名清单不再保留旧 Edge MSI 条目。
