# Browser Harbor v0.4.0

Chrome++ can now be checked and updated independently, with explicit browser-process protection and safe rollback.

Chrome++ 现在可以独立检查和更新，并具备明确的浏览器进程保护与安全回滚。

## 下载 · Download

Download **BrowserHarbor-0.4.0-x64.exe**. This EXE is sufficient for normal use.

普通使用只需下载 **BrowserHarbor-0.4.0-x64.exe**。

GitHub unavailable? Use the [Gitee mirror](https://gitee.com/MagicCube99/browser-harbor/releases).

无法访问 GitHub 时，可从 [Gitee 镜像](https://gitee.com/MagicCube99/browser-harbor/releases)下载。

The separately attached manifest, signature, and public key are optional for independent verification.

另附的清单、签名和公钥仅用于独立验证，可选下载。

## 主要变化 · Highlights

- Check Chrome++ without modifying files; a detected update becomes an explicit update action.
- Update Chrome++ without reinstalling or replacing the browser program.
- Browser upgrades show both the browser and Chrome++ version transitions before confirmation.
- Detect every process in the selected target’s program directory, including multiple windows, background processes, and Edge version folders.
- Other running browser brands do not block the update. Browser Harbor never force-closes a browser.
- Back up the INI and roll back replaced files if a Chrome++ update fails.
- Reuse one verified Chrome++ download for later targets while its SHA-256 cache remains.

- 检查 Chrome++ 时不会修改文件；发现新版本后显示明确的更新操作。
- 更新 Chrome++ 不要求重装或替换浏览器程序。
- 浏览器升级前会同时显示浏览器和 Chrome++ 的版本变化。
- 检测当前目标程序目录中的全部进程，包括多个窗口、后台进程和 Edge 不同版本目录。
- 其他浏览器品牌正在运行不会阻止操作；本工具绝不强制关闭浏览器。
- 更新失败时会恢复旧文件，并在修改前备份 INI。
- SHA-256 缓存仍存在时，后续目标复用同一已验证 Chrome++ 下载。

## 当前限制 · Current limitations

- Brave, Helium, and Ungoogled Chromium retain an experimental Chrome++ compatibility label.
- The EXE is not Authenticode-signed, so SmartScreen may show a warning.
- Existing arbitrary browser directories are not imported automatically.
