## 本次更新 · What's new

- “高级”新增自动检查校验信息、已签名离线回退和立即重新获取控件。
- Chrome++ 和 Libportable 更新可以更快进入签名校验流程。
- 发布构建使用最新的签名元数据快照，减少内置回退信息滞后。

- Advanced settings now include automatic verification checks, signed offline fallback, and manual refresh.
- Chrome++ and Libportable updates can enter the signed verification flow sooner.
- Release builds use the latest signed metadata snapshot, reducing stale embedded fallback data.

## 安全边界 · Verification boundary

离线回退只绕过实时新鲜度要求；Ed25519、文件大小和 SHA-256 校验始终强制执行。缺少可信摘要的新版本不会因为离线选项而变为可安装。

Offline fallback only bypasses the live-freshness requirement. Ed25519, size, and SHA-256 checks remain mandatory. A newer release without a trusted digest cannot be installed merely by enabling the offline option.

## 升级 · Upgrade

直接替换旧 EXE 即可。`BrowserHarbor.json`、已安装浏览器、用户数据、Profile 和缓存不会被删除。

Replace the old EXE. `BrowserHarbor.json`, installed browsers, user data, profiles, and caches are not removed.
