## 本次更新 · What's new

- 浏览器概览中的“来源”升级为可点击超链接，点击可直接在浏览器中打开该浏览器的官方网站或 GitHub Releases 发布页，悬停可查看详细说明。
- 增强安装与更新替换前的文件占用保护，当目标文件正被运行中的浏览器占用时自动阻止替换，避免程序崩溃。
- 在“检查配置”和状态提示中增加针对杀毒软件误报隔离的排查提示与排除指引。

- The "Source" label on the browser overview page is now a clickable hyperlink to each browser's official website or GitHub Releases page, with full URLs and hints on hover.
- Enhanced file-lock detection before browser installations and updates, safely blocking replacements while browser executables are in use to prevent crashes.
- Added actionable guidance in configuration diagnostics and status tooltips when browser executables are missing or quarantined by antivirus software.

## 升级 · Upgrade

直接替换旧 EXE 即可。`BrowserHarbor.json`、已安装浏览器、用户数据、Profile 和缓存不会被删除。

Replace the old EXE. `BrowserHarbor.json`, installed browsers, user data, profiles, and caches are not removed.
