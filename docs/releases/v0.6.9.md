# Browser Harbor v0.6.9

Adds Vivaldi browser support with double-layer 7z in-memory extraction and native standalone portable mode.

新增 Vivaldi 浏览器支持：采用双层 7z 内存受控解包与官方原生 Standalone 便携模式，零修改二进制并剔除后台更新器。

## 下载 · Download

Download **BrowserHarbor-0.6.9-x64.exe**. This EXE is sufficient for normal use.

普通使用只需下载 **BrowserHarbor-0.6.9-x64.exe**。

GitHub unavailable? Use the [Gitee mirror](https://gitee.com/MagicCube99/browser-harbor/releases).

无法访问 GitHub 时，可从 [Gitee 镜像](https://gitee.com/MagicCube99/browser-harbor/releases)下载。

## 调整与修复 · Changes & Fixes

- Added **Vivaldi** (Stable x64) as the 15th supported browser target.
- Pure in-memory double-layer 7z unpacking from the official installer without executing third-party installation binaries.
- Configures official native Standalone mode via `stp.viv`, keeping `User Data` strictly isolated in the browser root without touching registry or `%LOCALAPPDATA%`.
- Automatically strips `update_notifier.exe` during installation and update.
- Updated documentation and architecture specifications across all public and internal references.

- 新增 **Vivaldi**（Stable x64）作为第 15 款受支持的浏览器目标。
- 纯 Rust 内存静态受控解包官方安装包（双层 7z），绝不执行第三方安装程序。
- 写入官方原生 `stp.viv` 激活 Standalone 隔离模式，完全将 `User Data` 锁定在根目录，零修改二进制，不碰注册表与 `%LOCALAPPDATA%`。
- 安装与更新时自动剔除后台更新组件 `update_notifier.exe`。
- 全面对齐中英文文档、用户指南、ADR 决策与架构规范。
