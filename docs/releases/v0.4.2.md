# Browser Harbor v0.4.2

This patch makes the browser-directory controls easier to understand and
clarifies what Chrome++ does automatically.

本次补丁让浏览器目录设置更容易理解，并说明 Chrome++ 的自动安装与更新流程。

## 下载 · Download

Download **BrowserHarbor-0.4.2-x64.exe**. This EXE is sufficient for normal use.

普通使用只需下载 **BrowserHarbor-0.4.2-x64.exe**。

GitHub unavailable? Use the [Gitee mirror](https://gitee.com/MagicCube99/browser-harbor/releases).

无法访问 GitHub 时，可从 [Gitee 镜像](https://gitee.com/MagicCube99/browser-harbor/releases)下载。

The separately attached manifest, signature, and public key are optional for independent verification.

另附的清单、签名和公钥仅用于独立验证，可选下载。

## 调整 · Changed

- “Data directory” is now **User data directory**. Every directory label explains its purpose on hover.
- Profile is identified as an advanced per-profile subdirectory; clearing a required derived path restores the target default.
- The cache field is described as a cache root. Chromium usually stores HTTP cache below `<cache root>\<Profile>\Cache\Cache_Data`.
- Path changes for an existing browser are applied through **Check configuration** and its portable INI repair.

- “数据目录”改为 **用户数据目录**，所有目录标签都支持悬停查看用途。
- Profile 明确定位为具体用户配置子目录，属于高级设置；清空必填的派生路径会恢复目标默认值。
- 缓存字段明确为“缓存根”；Chromium 通常把 HTTP 缓存放在 `<缓存根>\<Profile>\Cache\Cache_Data`。
- 已安装浏览器修改路径后，需要通过“检查配置”更新便携运行时 INI。

## 修复 · Fixed

- Browser installation or upgrade automatically downloads, verifies, and installs Chrome++.
- A detected Chrome++ update is shown as pending until the confirmed replacement finishes.

- 浏览器安装或升级会自动下载、校验并安装 Chrome++。
- 检测到 Chrome++ 新版本时只显示待更新状态；确认并完成替换后版本才会变化。

## 当前限制 · Current limitations

- Brave, Helium, and Ungoogled Chromium retain an experimental Chrome++ compatibility label.
- The EXE is not Authenticode-signed, so SmartScreen may show a warning.
- Existing arbitrary browser directories are not imported automatically.
