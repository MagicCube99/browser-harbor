# Browser Harbor v0.9.3

## 下载 · Download

普通使用只需下载 **BrowserHarbor-0.9.3-x64.exe**。Windows 10/11 x64，无需安装。

Download **BrowserHarbor-0.9.3-x64.exe** for Windows 10/11 x64. No installation required.

[GitHub](https://github.com/MagicCube99/browser-harbor/releases/tag/v0.9.3) · [Gitee 国内下载](https://gitee.com/MagicCube99/browser-harbor/releases/tag/v0.9.3)

## 本次更新 · What's new

- 修复 Chrome Beta 安装后被误判为 Stable 或反复提示“渠道不同”的问题，同时修正 Edge、Brave 的同类识别逻辑。
- 切换所选渠道不再影响已安装渠道记录。安装渠道不同会先提示切换，涉及降级时仍需单独确认。

- Fixed Chrome Beta being incorrectly reported as Stable or showing a channel mismatch after installation; the same correction applies to Edge and Brave.
- Selecting another channel no longer changes the recorded installed channel. Channel switching and downgrading still require separate confirmations.

## 升级 · Upgrade

替换旧 EXE 即可，无需删除 `BrowserHarbor.json` 或浏览器用户数据。

**旧安装提示：** 对于旧版 Browser Harbor 安装的 Chrome、Edge、Brave，请使用 v0.9.3 重新安装所需渠道一次，以建立渠道记录；之后重启工具或切换 Stable/Beta 即可核验已安装渠道。

Replace the old EXE without deleting `BrowserHarbor.json` or browser user data.

**Existing installations:** For Chrome, Edge, or Brave installed with an older Browser Harbor version, reinstall the desired channel once using v0.9.3 to establish its channel record. The installed channel can then be verified after restarting the tool or switching between Stable and Beta.
