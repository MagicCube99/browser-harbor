# Browser Harbor v0.6.8

Refines cross-channel installation clarity, adds Iceweasel channel detection, and expands Floorp compatibility.

优化跨渠道安装体验与按钮文案，补齐 Iceweasel 渠道识别，并前瞻放宽 Floorp 兼容门禁。

## 下载 · Download

Download **BrowserHarbor-0.6.8-x64.exe**. This EXE is sufficient for normal use.

普通使用只需下载 **BrowserHarbor-0.6.8-x64.exe**。

GitHub unavailable? Use the [Gitee mirror](https://gitee.com/MagicCube99/browser-harbor/releases).

无法访问 GitHub 时，可从 [Gitee 镜像](https://gitee.com/MagicCube99/browser-harbor/releases)下载。

## 调整与修复 · Changes & Fixes

- When an installed browser has a different channel than the selected one, the overview shows **Channel mismatch** and the button states **Install using {Channel} channel** (or **Install from local {Channel} package**).
- Added channel detection for Iceweasel to distinguish between ESR and Release.
- Forward-expanded Floorp Libportable version gate to v12–v14.

- 跨渠道切换时，常规页徽标显示“渠道不同”，主操作按钮直接明确为“使用 {渠道} 渠道安装”（或“使用本地 {渠道} 离线包安装”）。
- 补齐 Iceweasel 渠道探测能力（区分 ESR 与 Release）。
- 前瞻放宽 Floorp 的 Libportable 兼容门禁至 v12~v14。
