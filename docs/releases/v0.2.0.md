# Browser Harbor v0.2.0 — Verified Edition

The first stable Browser Harbor release with verified release metadata and automatic upstream checks.
首个带验证发布元数据和自动上游检查的 Browser Harbor 稳定版。

## 下载 · Download

Download only **BrowserHarbor-0.2.0-x64.exe**.

只需下载 **BrowserHarbor-0.2.0-x64.exe**。

The executable contains the signed metadata and public key. The separate manifest assets are optional and intended for manual verification.

EXE 已内嵌签名清单和公钥；单独的清单资产仅用于人工验证。

## 主要变化 · Highlights

- One Verified Edition EXE for 14 browser targets.
- Ed25519-verified metadata with no operational expiry.
- Signed metadata refresh through GitHub Actions without a new EXE or Release.
- Automatic upstream checks on the browser page and ten-minute verified-result reuse.
- Required integrity checks for browsers, Chrome++, Libportable, and local packages.
- Chinese and English interface switching with immediate autosave.

## 发布策略 · Release policy

From `v0.2` onward, Browser Harbor publishes one Verified Edition EXE per release. There is no unsigned or no-verification build. The archived `v0.1.0` compatibility release is historical only.

从 `v0.2` 起，Browser Harbor 每个版本只发布一个 Verified Edition EXE，不提供无签名或不校验构建。`v0.1.0` 兼容版仅为历史归档。
