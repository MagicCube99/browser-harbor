## 本次更新 · What's new

- 正式终止对 Microsoft Edge 的支持，受支持的浏览器调整为 14 款。微软在 Edge 119+ 的沙盒渲染子进程中强制启用内核级代码完整性保护，非微软签名的便携组件会被系统拦截并导致标签页崩溃；官方也已废弃相关绕过开关。详细说明见 README 的“关于已终止支持的浏览器”。
- 旧配置中选中 Edge 的用户，升级后会自动回落到 Google Chrome 启动；本次变更不会删除或修改任何浏览器程序、Profile 与用户数据。
- 移除了仅为 Edge 维护的启动器、安装分支与诊断逻辑，其余 14 款浏览器继续使用各自的原生便携布局，不再有特例。
- 其余下载、校验、解压、便携化与诊断行为保持不变。

- Microsoft Edge support has been discontinued; Browser Harbor now manages 14 browsers. Microsoft enforces kernel-level Code Integrity on Edge 119+ sandboxed renderers, so non-Microsoft portable components are blocked and pages crash; the official bypass switches have also been retired. See "Unsupported Browsers" in the README for details.
- If your configuration selected Edge, the next launch opens on Google Chrome instead. No browser files, profiles, or user data are deleted or modified by this change.
- Edge-only launcher, installation and diagnostic handling has been removed; the remaining 14 browsers keep their native portable layouts with no special cases.
- Downloading, verification, extraction, portability and diagnostics are otherwise unchanged.

## 升级 · Upgrade

直接替换旧 EXE 即可。`BrowserHarbor.json`、已安装浏览器、用户数据、Profile 和缓存不会被删除。
若此前选中 Edge，程序会自动改为选中 Chrome，原有 Edge 目录与数据保持原样，不会被删除。

Replace the old EXE. `BrowserHarbor.json`, installed browsers, user data, profiles, and caches are not removed.
If Edge was selected, the app selects Chrome instead; the existing Edge directory and its data are left untouched.
