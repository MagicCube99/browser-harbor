# Browser Harbor v0.6.6

Fixes legacy configuration profile drift and improves permission guidance for protected Windows directories.

修复老版本配置升级后的 Profile 影子字段漂移，并增加受保护 Windows 目录的写权限诊断指引。

## 下载 · Download

Download **BrowserHarbor-0.6.6-x64.exe**. This EXE is sufficient for normal use.

普通使用只需下载 **BrowserHarbor-0.6.6-x64.exe**。

GitHub unavailable? Use the [Gitee mirror](https://gitee.com/MagicCube99/browser-harbor/releases).

无法访问 GitHub 时，可从 [Gitee 镜像](https://gitee.com/MagicCube99/browser-harbor/releases)下载。

## 修复 · Fixed

- Fixed false-positive errors in **Check configuration** for upgraded legacy configurations by automatically normalizing single-directory targets upon load.
- Clarified error messages and provided guidance when writing to protected directories like C:\ or Program Files.
- Updated configuration location explanation to recommend standard user directories.

- 修复老版本配置升级后因内部影子 Profile 路径未同步导致“检查配置”报红、必须手动重选一次的问题；现在加载时自动对齐。
- 当在 C 盘根目录或 Program Files 等受保护目录下遭遇写权限拒绝时，给出清晰的迁移普通目录（如 D 盘或 C:\Tools）或管理员运行指引。
- 全局设置的配置位置说明明确提示避免放在 C 盘根目录或 Program Files 等受保护位置。
