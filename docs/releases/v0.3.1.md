# Browser Harbor v0.3.1

This patch cleans up the Chrome++ page hierarchy and lets footer status messages use the available width without covering controls.

本次补丁整理 Chrome++ 页面层级，并让底栏状态在充分利用可用宽度的同时不再遮挡右侧控件。

## 下载 · Download

Download **BrowserHarbor-0.3.1-x64.exe**. This EXE is sufficient for normal use.

普通使用只需下载 **BrowserHarbor-0.3.1-x64.exe**。

GitHub unavailable? Use the [Gitee mirror](https://gitee.com/MagicCube99/browser-harbor/releases).

无法访问 GitHub 时，可从 [Gitee 镜像](https://gitee.com/MagicCube99/browser-harbor/releases)下载。

The separately attached manifest, signature, and public key are optional for independent verification.

另附的清单、签名和公钥仅用于独立验证，可选下载。

## 主要变化 · Highlights

- The Chrome++ integration and configuration cards now share the same heading rhythm.
- The installed Chrome++ version and compact update action now sit in the integration heading row.
- Footer status text uses every available pixel before the right-side controls.
- Long footer messages still truncate before the language, appearance, settings, and version controls.

- Chrome++ 集成卡片与配置文件卡片现在共享一致的标题行节奏。
- Chrome++ 已安装版本及紧凑更新操作现在位于集成卡片标题行。
- 底栏状态文字会用尽右侧控件之前的全部可用宽度。
- 长状态消息仍会在语言、外观、全局设置和版本控件之前截断。

## 当前限制 · Current limitations

- Brave, Helium, and Ungoogled Chromium retain an experimental Chrome++ compatibility label.
- The EXE is not Authenticode-signed, so SmartScreen may show a warning.
- Existing arbitrary browser directories are not imported automatically.
