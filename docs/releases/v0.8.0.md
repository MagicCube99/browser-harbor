## 本次更新 · What's new

- 下载时优先选择响应更快的可用加速线路，遇到失效或停滞线路会更快切换。
- 大型下载中断后可以继续，减少重复传输；最终大小和摘要校验仍然强制执行。
- 新发布的浏览器版本可以更快进入安装流程。

- Browser Harbor now prefers responsive accelerators and switches away from stalled routes sooner.
- Interrupted large downloads can resume when the source and cached data still match, reducing repeated transfer.
- Newly published browser releases can become available for installation sooner.

## 升级 · Upgrade

直接替换旧 EXE 即可。`BrowserHarbor.json`、已安装浏览器、用户数据、Profile 和缓存不会被删除。

Replace the old EXE. `BrowserHarbor.json`, installed browsers, user data, profiles, and caches are not removed.

所有浏览器、便携运行时和本地安装包仍须通过大小、摘要及必要的签名校验。

Every browser, portable runtime, and local package still requires size, digest, and applicable signature verification.
