# Browser Harbor v0.6.5

Local package selection now says exactly what it does and what it verifies.

本地安装包入口现在会清楚说明它的用途和校验范围。

## 下载 · Download

Download **BrowserHarbor-0.6.5-x64.exe**. This EXE is sufficient for normal use.

普通使用只需下载 **BrowserHarbor-0.6.5-x64.exe**。

GitHub unavailable? Use the [Gitee mirror](https://gitee.com/MagicCube99/browser-harbor/releases).

无法访问 GitHub 时，可从 [Gitee 镜像](https://gitee.com/MagicCube99/browser-harbor/releases)下载。

## 调整 · Changed

- **Choose local installer package** replaces the old **Load local package** label.
- The selected target, channel, build, and file path appear in the footer.
- The install action changes to local-package wording instead of saying it will download.
- Local-package mismatch errors name the expected browser, version, and file.

- “选择本地安装包”取代旧的“载入本地包”。
- 底栏显示当前目标、渠道、构建和文件路径。
- 安装动作改为本地包专用文案，不再暗示会下载浏览器。
- 本地包不匹配时明确提示期望的浏览器、版本和文件名。
