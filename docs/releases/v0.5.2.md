# Browser Harbor v0.5.2

This patch tidies the global-settings form. The timeout and proxy inputs now
share one left edge, and the current configuration path uses the full remaining
row instead of being confined to a narrow column. The proxy and cache cards now
keep equal height, and English settings fit without scrolling.

本次补丁整理了全局设置表单：超时与代理地址输入框使用同一条左边缘，当前配置文件
路径占满整行剩余空间，代理与缓存卡片保持等高；英文界面无需滚动即可完整显示。

## 下载 · Download

Download **BrowserHarbor-0.5.2-x64.exe**. This EXE is sufficient for normal use.

普通使用只需下载 **BrowserHarbor-0.5.2-x64.exe**。

GitHub unavailable? Use the [Gitee mirror](https://gitee.com/MagicCube99/browser-harbor/releases).

无法访问 GitHub 时，可从 [Gitee 镜像](https://gitee.com/MagicCube99/browser-harbor/releases)下载。

The separately attached manifest, signature, and public key are optional for independent verification.

另附的清单、签名和公钥仅用于独立验证，可选下载。

## 调整 · Changed

- Timeout and proxy inputs now align on the same left edge.
- The current configuration path uses the full remaining row width.
- Proxy and cache cards keep equal height, with the cache cleanup explanation moved to a tooltip.
- English global settings fit without scrolling and include complete localized labels.

- 超时与代理地址输入框现在严格左对齐。
- 当前配置文件路径使用整行剩余宽度。
- 代理与缓存卡片保持等高，缓存清理说明改为悬停查看。
- 英文全局设置无需滚动，并补齐配置文件路径标签。

## 当前限制 · Current limitations

- Brave, Helium, and Ungoogled Chromium retain an experimental Chrome++ compatibility label.
- The EXE is not Authenticode-signed, so SmartScreen may show a warning.
