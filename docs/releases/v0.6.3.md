# Browser Harbor v0.6.3

Browser Harbor v0.6.3 fixes folder selection when a directory has a sibling
archive with the same base name.

Browser Harbor v0.6.3 修复同一目录中存在同名文件夹和压缩包时，目录选择器报错的问题。

## 下载 · Download

Download **BrowserHarbor-0.6.3-x64.exe**. This EXE is sufficient for normal use.

普通使用只需下载 **BrowserHarbor-0.6.3-x64.exe**。

GitHub unavailable? Use the [Gitee mirror](https://gitee.com/MagicCube99/browser-harbor/releases).

无法访问 GitHub 时，可从 [Gitee 镜像](https://gitee.com/MagicCube99/browser-harbor/releases)下载。

## 修复 · Fixed

- A folder named `Iceweasel` and a sibling `Iceweasel.zip` no longer trigger Windows Shell’s “folder unavailable” error. The picker starts in their parent directory.
- Same-name folder/archive collisions are detected without relying on the Explorer extension-display setting.

- `Iceweasel` 文件夹与同目录的 `Iceweasel.zip` 不再触发 Windows Shell“当前不可用”；选择器改为从父目录打开。
- 同类文件夹/压缩包同名冲突会被自动识别，不依赖资源管理器的扩展名显示设置。
