# Browser Harbor v0.7.0

## 下载 · Download

普通使用只需下载 **BrowserHarbor-0.7.0-x64.exe**。Windows 10/11 x64，无需安装。

Download **BrowserHarbor-0.7.0-x64.exe** for Windows 10/11 x64. No installation required.

[GitHub](https://github.com/MagicCube99/browser-harbor/releases/tag/v0.7.0) · [Gitee 国内下载](https://gitee.com/MagicCube99/browser-harbor/releases/tag/v0.7.0)

## 本次更新 · What's new

- 新增 Catsxp Beta，修复 Catsxp 正式版与 Beta 无法使用指定用户数据和缓存目录的问题。
- 修复部分浏览器更新后 Chrome++ 仍为旧版、却提示已更新的问题。
- 改进安装中断后的重试恢复、配置自动保存和网络错误提示。
- 本地包入口改为“选择当前版本包”，默认隐藏，可在“全局设置 → 高级”开启；仅支持本次检查到的官方发布版本。

- Added Catsxp Beta and fixed user-data and cache paths in both Catsxp channels.
- Fixed some browser updates leaving Chrome++ unchanged while reporting it as updated.
- Improved recovery when retrying interrupted installations, settings autosave, and network error messages.
- Renamed the local-package option to **Choose current release package**. Enable it under **Global settings → Advanced**; it only accepts the official release found by the current check.

## 使用提醒 · Before you start

已有 Catsxp 安装请重新下载安装或同版替换一次，以更新路径配置。之前保存在系统用户目录中的数据不会自动迁移，请保留原数据。

For an existing Catsxp installation, reinstall or replace the same version once to update its path settings. Data previously saved in the Windows user directory is not moved automatically; keep that data.

部分远程桌面环境可能无法启动程序，可尝试在本地桌面运行。

The app may not open in some Remote Desktop environments. Try running it on the local desktop.
