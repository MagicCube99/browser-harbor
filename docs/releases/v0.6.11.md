# Browser Harbor v0.6.11

Fixes fresh-install Chrome++ notices, Vivaldi signed metadata lookup, and stale Edge version results.

修复首次安装时的 Chrome++ 提示、Vivaldi 签名清单查询和 Edge 旧版本信息回退。

## 下载 · Download

Download **BrowserHarbor-0.6.11-x64.exe**. The EXE is sufficient for normal use.

普通使用只需下载 **BrowserHarbor-0.6.11-x64.exe**。

[Gitee mirror · 国内下载](https://gitee.com/MagicCube99/browser-harbor/releases)

## 调整与修复 · Changes & Fixes

- Fresh browser installations no longer claim Chrome++ was upgraded from a historical version.
- Vivaldi works with older local metadata caches: missing entries trigger a refresh, with a verified embedded manifest available as a fallback.
- Edge uses Microsoft's live download information and rejects obsolete MSI records. Failed checks no longer leave an old result displayed as current.
- A newer installed browser is labeled **Local version is newer**.

- 首次安装浏览器不再误报 Chrome++ 从历史版本升级。
- 旧缓存没有 Vivaldi 时自动刷新；新版内置已验签清单也包含 Vivaldi。
- Edge 继续使用 Microsoft 实时下载信息，拒绝旧 MSI 记录；检查失败后不会继续把旧结果当作当前结果。
- 已安装浏览器高于查询结果时，明确显示“本地版本较新”。
