# Browser Harbor v0.6.4

The footer update indicator is now easier to notice without making the footer
noisier.

底栏更新提示现在更容易被发现，同时保持界面紧凑。

## 下载 · Download

Download **BrowserHarbor-0.6.4-x64.exe**. This EXE is sufficient for normal use.

普通使用只需下载 **BrowserHarbor-0.6.4-x64.exe**。

GitHub unavailable? Use the [Gitee mirror](https://gitee.com/MagicCube99/browser-harbor/releases).

无法访问 GitHub 时，可从 [Gitee 镜像](https://gitee.com/MagicCube99/browser-harbor/releases)下载。

## 调整 · Changed

- When a newer stable release is available, the footer version becomes a highlighted chip.
- Clicking it opens a compact GitHub/Gitee release-site menu.

- 发现新稳定版时，底栏版本入口会变成醒目的强调色胶囊。
- 点击后可选择 GitHub 或 Gitee 发布页，菜单保持紧凑。
