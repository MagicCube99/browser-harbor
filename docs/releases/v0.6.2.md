# Browser Harbor v0.6.2

Browser Harbor now notices its own stable updates without replacing a running
EXE. The footer version link gains an arrow when a newer release is available.

Browser Harbor 现在能发现自身稳定版更新，但不会替换正在运行的 EXE。发现新版本时，
底栏版本链接会显示箭头。

## 下载 · Download

Download **BrowserHarbor-0.6.2-x64.exe**. This EXE is sufficient for normal use.

普通使用只需下载 **BrowserHarbor-0.6.2-x64.exe**。

GitHub unavailable? Use the [Gitee mirror](https://gitee.com/MagicCube99/browser-harbor/releases).

无法访问 GitHub 时，可从 [Gitee 镜像](https://gitee.com/MagicCube99/browser-harbor/releases)下载。

## 新增 · Added

- A lightweight startup check marks newer stable Browser Harbor releases in the footer.

- 启动时轻量检查最新稳定版，并在底栏标记新版本。

## 修复 · Fixed

- Folder and file pickers canonicalize their starting directory and fall back to an existing parent.

- 系统目录和文件选择器会规范化起始目录，并回退到有效上级目录。

## 当前限制 · Current limitations

- Browser Harbor reports updates but does not replace its own running EXE.
- The EXE is not Authenticode-signed, so SmartScreen may show a warning.

## 校验 · Verify

The release page appends the final EXE and metadata SHA-256 values after the
workflow builds the assets.
