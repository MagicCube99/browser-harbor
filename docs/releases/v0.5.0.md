# Browser Harbor v0.5.0

This release makes manager configuration portable and removes an unnecessary
Profile field from browsers that do not need one.

本次更新让管理器配置可以随程序携带，并移除大多数浏览器中重复的 Profile 输入项。

## 下载 · Download

Download **BrowserHarbor-0.5.0-x64.exe**. This EXE is sufficient for normal use.

普通使用只需下载 **BrowserHarbor-0.5.0-x64.exe**。

GitHub unavailable? Use the [Gitee mirror](https://gitee.com/MagicCube99/browser-harbor/releases).

无法访问 GitHub 时，可从 [Gitee 镜像](https://gitee.com/MagicCube99/browser-harbor/releases)下载。

The separately attached manifest, signature, and public key are optional for independent verification.

另附的清单、签名和公钥仅用于独立验证，可选下载。

## 新增 · Added

- Choose whether `manager.json` stays in `%LOCALAPPDATA%\browser-harbor` or moves beside the EXE for portable use.
- Portable configuration requires a writable EXE directory. Temporary directories are not used for persistent settings.

- `manager.json` 可保存在 `%LOCALAPPDATA%\browser-harbor`，也可移动到 EXE 旁随程序携带。
- 便携配置要求 EXE 所在目录可写；临时目录不会用于保存持久设置。

## 调整 · Changed

- Most browser pages now show only **User data directory**; the internal Profile path follows it automatically.
- **Profile location** remains visible only for Floorp and LibreWolf, whose distributions need a separate profile location.
- Configuration diagnostics and relocation previews use the same rule and omit duplicate Profile rows.
- Moving only the JSON to another computer does not convert stored absolute browser paths; use **Check configuration** and **Relocate…** if they change.

- 大多数浏览器页只显示“用户数据目录”，内部 Profile 路径会自动跟随。
- 只有 Floorp 和 LibreWolf 需要独立 Profile 位置时才显示该字段。
- 配置检查和重新定位预览采用相同规则，不再显示重复的 Profile 行。
- 仅把 JSON 复制到另一台电脑不会转换其中的绝对浏览器路径；路径变化时请使用“检查配置”和“重新定位…”。

## 当前限制 · Current limitations

- Brave, Helium, and Ungoogled Chromium retain an experimental Chrome++ compatibility label.
- The EXE is not Authenticode-signed, so SmartScreen may show a warning.
