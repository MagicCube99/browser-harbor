# Browser Harbor v0.6.1

Browser Harbor v0.6.1 fixes the daily signed metadata refresh and makes path
examples match the browser you are configuring.

Browser Harbor v0.6.1 修复每日签名发布清单刷新，并让路径示例跟随当前正在配置的浏览器。

## 下载 · Download

Download **BrowserHarbor-0.6.1-x64.exe**. This EXE is sufficient for normal use.

普通使用只需下载 **BrowserHarbor-0.6.1-x64.exe**。

GitHub unavailable? Use the [Gitee mirror](https://gitee.com/MagicCube99/browser-harbor/releases).

无法访问 GitHub 时，可从 [Gitee 镜像](https://gitee.com/MagicCube99/browser-harbor/releases)下载。

The separately attached manifest, signature, and public key are optional for independent verification.

另附的清单、签名和公钥仅用于独立验证，可选下载。

## 修复 · Fixed

- Daily signed metadata now refreshes reliably for Catsxp and other browsers whose artifact hash must be calculated locally.
- A source failure for one browser no longer blocks refreshes for the rest of the manifest; the previous signed entry is retained.
- The Browser Root example now follows the selected browser.

- Catsxp 以及其他需要本地计算制品摘要的浏览器，现在可以可靠刷新每日签名清单。
- 单个浏览器来源刷新失败不再阻塞整份清单，继续保留该浏览器上一份已签名条目。
- “浏览器根目录”的示例路径现在跟随当前选中的浏览器。

## 当前限制 · Current limitations

- Edge Beta uses Microsoft's live CDP artifact URL, so it is resolved online but is not stored in the long-lived signed metadata manifest.
- Brave, Helium, and Ungoogled Chromium retain an experimental Chrome++ compatibility label.
- The EXE is not Authenticode-signed, so SmartScreen may show a warning.
