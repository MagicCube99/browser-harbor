# Browser Harbor v0.2.0-beta.3 — Verified Edition Beta

Automatically checks upstream metadata when a browser page is opened and reuses a recent verified result for installation.
打开浏览器页时自动检查上游，并在安装时复用近期已验证结果。

## 下载 · Download

Download only **BrowserHarbor-0.2.0-beta.3-x64.exe**.

只需下载 **BrowserHarbor-0.2.0-beta.3-x64.exe**。

## 可选验证资产 · Optional verification assets

The executable contains the signed metadata and public key. Separate manifest assets are optional and intended for manual verification.

## 交互变化 · Workflow changes

- Each target/channel/build is checked once per session when the browser page is opened.
- Installed browsers with no upstream result show **检查并安装/升级**.
- Manual **检查更新** remains available.
- An install started within ten minutes reuses the matching verified release descriptor, avoiding a second metadata resolution.
- Missing or stale cached results are resolved normally at install time.

## 元数据更新 · Metadata updates

Browser version changes continue to update the signed manifest through GitHub Actions without a new EXE release.
